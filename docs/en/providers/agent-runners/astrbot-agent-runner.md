# Built-in Agent Runner

By default, WonderBot uses the built-in Agent Runner as the default executor. You don't need to configure anything to use WonderBot's powerful built-in Agent Runner.

![image](https://files.wonderbot.dev/docs/source/images/astrbot-agent-runner/image.png)

With the built-in Agent Runner, you can use WonderBot's [MCP Server](/use/mcp), [Knowledge Base](/use/knowledge-base), [Web Search](/use/websearch), and persona features.
