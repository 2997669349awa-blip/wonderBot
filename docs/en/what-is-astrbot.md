# 👋 I'm WonderBot

## Introduction

WonderBot is an open-source, all-in-one Agentic assistant for personal and group chats. It can be deployed across dozens of mainstream instant messaging platforms, such as QQ, Telegram, WeCom, Lark, DingTalk, and Slack. It also includes a lightweight built-in ChatUI (similar to OpenWebUI), providing reliable and extensible conversational AI infrastructure for individuals, developers, and teams. Whether you are building a personal AI companion, an intelligent customer service assistant, an automation bot, or an enterprise knowledge base, WonderBot helps you build AI applications directly inside your IM workflows.

## Documentation Overview

This documentation is divided into the following sections:

- **Deployment**: multiple ways to quickly deploy WonderBot on local machines or cloud servers.
- **Messaging Platform Integration**: integration guides for 18+ mainstream instant messaging platforms.
- **AI Provider Integration**: connect to model providers, use WonderBot's built-in Agent Runner, or integrate third-party Agent Runner services such as Dify, Coze, Alibaba Bailian, and DeerFlow.
- **Usage Guides**: practical guides for features such as plugins, tool calling, knowledge base, MCP, Skills, and Agent sandbox.

## Quick Start

- Deploy WonderBot: Read the Deployment Guide to quickly deploy WonderBot on your local machine or cloud server.
- Connect to IM platforms: Follow the instructions to connect WonderBot to your preferred IM platforms such as Discord, Telegram, Slack, etc.
- Configure AI models: WonderBot supports various AI models. See [Connecting Model Services](/en/providers/start)
